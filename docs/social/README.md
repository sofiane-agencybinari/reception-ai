## Règles de posting (logo en cours)

- Visuel : fond sombre / ambiance cuisine / mock écran — **pas besoin du logo final**.
- Texte overlay court (hook 5–8 mots).
- Toujours un CTA cliquable vers `/demo` (bio + premier commentaire si besoin).
- Hashtags FR locaux : 3–5 max (`#fastfood` `#idf` `#restauration` `#ia` `#pizzeria`).
