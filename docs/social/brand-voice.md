# ASTOR — Brand voice (court)

## En une phrase

Épure, resto, futuriste — **sans jargon tech**. On parle comme un gérant qui a compris le produit, pas comme une startup IA.

## Ton

| Oui | Non |
| --- | --- |
| Direct, concret, terrain | Buzzwords (`synergie`, `disruptif`, `agent LLM`) |
| Calme et sûr | Criard, “révolutionnaire !!!” |
| Bénéfice métier (CA, rush, cuisine) | Features abstraites |
| Phrases courtes | Blocs marketing dilués |
| FR pro mais accessible | Anglais forcé / anglicismes inutiles |

## Vocabulaire ASTOR

**Utiliser :** décrocher · commande · rush · écran cuisine · appels manqués · prep · bon · confirmation SMS · essai · demo voix  

**Éviter :** chatbot · NLP · prompt · orchestration · pipeline · SaaS (sauf LinkedIn B2B léger) · “intelligence artificielle générative”

## Formules type

- Hook douleur → preuve simple → CTA demo
- “Pendant que tu es en cuisine…”
- “Zéro tonalité occupée.”
- “De l’appel à la plancha.”

## Interdits

- Promettre “100 % parfait” ou “remplace toute l’équipe”
- Attaquer nommément un concurrent
- Prix inventés (référence site : 49 / 99 / 199 € + /min)
- Emojis en cascade (1–2 max, ou zéro sur LinkedIn)

## Signature CTA

Toujours la même hiérarchie :

1. **Demo** → `/demo`
2. **Essai** → `/#contact` (ou mail)
3. **Tarifs** → `/#tarifs` si question prix
